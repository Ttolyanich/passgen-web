How to Make a Wi-Fi QR Code

  1. Type the network name exactly as it appears in your phone’s Wi-Fi list. Capitals and spaces count.
  2. Type the password, or make a new one with the refresh button, copy it, and set the same one on your router.
  3. Check the security type. Almost every router today uses WPA2 or WPA3. Choose None only for an open network, and turn on Hidden network if your network does not show up in the list.
  4. Test it with your own phone before you print: forget the network on your phone, scan the code, and join.
  5. Download or print it. PNG for a screen or a document, SVG for a print shop (sharp at any size), or Print sign for a ready-made sign.

How Guests Scan It

iPhone and iPad: open the Camera app, point it at the code, and tap the “Join network” notice that appears.

Android: open the Camera app or Google Lens and point it at the code. On many phones you can also go to Settings, then Wi-Fi, and tap the QR icon next to Add network.

Laptops, TVs, and game consoles usually have no camera, which is why the printed card also shows the network name and password in large type.

What Is Inside a Wi-Fi QR Code

Just a line of text in a standard format that phone cameras recognize. The code on the sign above holds this:

WIFI:T:WPA;securityS:Luna Cafe Guests;network nameP:tulip-crisp-oak-canal-olive-47;password;

If a name or password contains ;, ,, :, \, or ", each one needs a backslash in front of it, or the phone reads the wrong name or password. This generator adds them for you, so passwords with symbols work. To see the exact text in your own code, open “What is in the code” under it: the password stays dotted unless you show it.

Who Can Use the Code

Anyone who can see the sign can join your network, and any QR reader app shows the password as plain text. So treat the sign like the password: keep it inside, where only your guests see it. If many people pass through, such as in a rental or an office, turn on your router’s guest network and make the code for that one, then change its password between tenants and print a new sign.

Frequently Asked Questions

Can I create a Wi-Fi QR code for free?

Yes. There is no sign-up, no watermark, and no limit. Download the image or print the sign as many times as you like.

Does a Wi-Fi QR code expire?

No. The network name and password are stored in the code itself, so it works for as long as they stay the same. If you change your Wi-Fi password, make a new code.

How do I find my current Wi-Fi password?

It is often printed on a sticker on the router. On Android, open Settings, then Wi-Fi, tap your network, and choose Share: the phone shows the password and its own QR code. On an iPhone, open Settings, then Wi-Fi, tap the info button next to your network, and tap Password.

Can I make a QR code for an open network?

Yes. Set the security type to None and leave out the password. The code still saves guests from finding and typing the network name.

Why won’t my phone join with the code?

Usually the network name or password differs by a capital letter or a space. Check both against your router. If the network is hidden, turn on Hidden network. Very old phones may not read Wi-Fi codes in the camera at all and need a QR reader app.

Is it safe to put my Wi-Fi password into a website?

Only into one that does not send it anywhere. When we tested 19 popular Wi-Fi QR code tools, 9 sent the password to their own server, and 4 of those still served it at a public address hours later. Seven also broke any password containing a semicolon, so the code could not join. Here the code is drawn by your browser, and the password never leaves your device.

How do I add a device to my Wi-Fi with a QR code?

Point the phone’s camera at the code and tap the notice that appears. On Android you can also open Settings, then Wi-Fi, and tap the QR icon next to Add network. Devices without a camera, such as a laptop or a TV, need the network name and password typed in, which is why the sign shows both.

Can I share my Wi-Fi password from my iPhone?

Yes, with another Apple device nearby: when it tries to join, your iPhone offers to share the password. On iOS 18 and later, the Passwords app can also show a QR code for a network you have joined: open Passwords, tap Wi-Fi, choose the network, and tap Show Network QR Code. For a printed sign, or a network you are not connected to, use this page.

What is the safest way to share a Wi-Fi password?

Give guests their own network: turn on your router’s guest network and make the code for that one, so they never get your main password. Show the code or a sign inside rather than sending the password by text or email, and change the guest password now and then, printing a new sign when you do.
