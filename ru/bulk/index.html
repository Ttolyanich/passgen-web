Генератор паролей списком

Создайте пароли для всей команды, компании или класса за один раз — до 1 000 паролей сразу, бесплатно и без регистрации. (Если нужен один пароль, используйте генератор паролей.) Вставьте список имён или адресов электронной почты либо просто укажите количество — и для каждого будет создан логин и пароль. Скачайте CSV-файл, готовый для импорта в Microsoft Entra (Microsoft 365), Google Workspace или Active Directory, или распечатайте отдельный бланк для каждого, чтобы раздать их лично.

Импорт файла

По умолчанию кнопка скачивания сохраняет файл в формате CSV; другой формат можно выбрать с помощью маленькой стрелки рядом с ней. Каждый формат соответствует шаблону загрузки своей системы:

  • Microsoft Entra: в центре администрирования Microsoft Entra откройте «Пользователи», затем «Массовые операции», затем «Массовое создание» и загрузите файл. Каждый логин должен быть адресом электронной почты в домене, который ваша организация добавила в Microsoft Entra. В шаблоне Microsoft нет столбца для смены пароля при следующем входе.
  • Google Workspace: в консоли администратора Google откройте «Каталог», затем «Пользователи», затем «Массовое обновление пользователей» и загрузите файл. Все пользователи попадут в организационное подразделение верхнего уровня, обозначенное как / в столбце Org Unit Path. Измените значения в этом столбце, чтобы поместить пользователей в другое подразделение, например /Sales.
  • Active Directory: файл содержит столбцы, необходимые команде PowerShell New-ADUser. Например:
    Import-Csv passwords-ad.csv | ForEach-Object {
  New-ADUser -Name $_.Name `
    -GivenName $_.GivenName -Surname $_.Surname -DisplayName $_.DisplayName `
    -SamAccountName $_.SamAccountName `
    -UserPrincipalName $_.UserPrincipalName `
    -AccountPassword (ConvertTo-SecureString $_.AccountPassword -AsPlainText -Force) `
    -ChangePasswordAtLogon ($_.ChangePasswordAtLogon -eq '$true') `
    -Enabled $true
}
  • CSV: имя, логин, пароль и указание, нужно ли сменить его при следующем входе, — для любой другой системы или электронной таблицы.

Вставляйте прямо из электронной таблицы. Первая строка с названиями столбцов, например «Имя» и «Электронная почта», пропускается, как и дополнительные столбцы, например с должностью, а также маркеры списка и нумерация. Строка, из-за которой импорт завершился бы ошибкой, например с дубликатом логина или опечаткой в адресе электронной почты, будет отмечена. Файлы для Microsoft Entra, Google Workspace и Active Directory станут доступны после исправления ошибки. Два человека с одинаковым именем — не проблема: второй получит логин с номером, например sean.murphy2.

Имена пользователей. Если рядом с именем нет адреса электронной почты, логин создаётся на основе имени, например grace.hopper. В режиме «Только количество» создаются логины user01, user02 и так далее. Для Microsoft Entra и Google Workspace нужен полный адрес электронной почты, поэтому введите свой почтовый домен в появившееся поле — и grace.hopper превратится в user@example.com.

Безопасно для электронных таблиц. Ни один пароль не начинается с =, +, - или @, а из имён эти символы в начале удаляются, поэтому электронная таблица никогда не выполнит содержимое ячейки как формулу.

Как безопасно раздать пароли

  • Распечатайте бланки вместо того, чтобы делиться списком. На каждом бланке указаны имя, логин и пароль одного человека. При желании можно добавить заголовок и адрес для входа. Разрежьте листы на отдельные бланки и раздайте их, чтобы никто не мог подсмотреть пароль на экране или доске.
  • Оставьте настройку «Сменить при следующем входе» включённой. Вы видели все пароли, поэтому каждому пользователю следует сменить свой пароль при первом входе. Эта настройка включается в файлы для Google Workspace и Active Directory, а также в CSV-файлы и бланки.
  • Не отправляйте список по электронной почте. Письма долго хранятся во многих местах.
  • Удалите файл после импорта и очистите корзину. Когда все пользователи войдут в свои аккаунты, первоначальные пароли больше никому не понадобятся.

Часто задаваемые вопросы

Как массово сгенерировать пароли?

Вставьте в поле список имён или адресов электронной почты — по одному человеку на строку — или выберите «Только количество». Рядом с каждым человеком сразу появится пароль. Затем скачайте файл для вашей системы, нажмите «Копировать всё» или распечатайте отдельный бланк для каждого человека.

Сколько паролей можно создать за один раз?

В режиме «Только количество» введите любое число от 1 до 1 000 или выберите один из предложенных вариантов. Если вы вставите список, для каждой строки будет создан один пароль. Тысяча паролей создаётся примерно за секунду.

Можно ли создавать имена пользователей и пароли одновременно?

Да. Вставьте имена, и для каждого человека будет создан логин на основе его имени, например grace.hopper. Если вы укажете почтовый домен, он будет добавлен к логину. Если вставить адреса электронной почты или готовые логины, они будут использованы без изменений. Для игровых ников и имён в соцсетях попробуйте генератор имён пользователей.

Можно ли создать список паролей в Excel?

Да. Скачайте CSV-файл и откройте его в Excel или нажмите «Копировать всё» и вставьте данные в таблицу: имена, логины и пароли попадут в отдельные столбцы.

Есть ли в Excel генератор паролей?

Нет. Формулы на основе RAND (СЛЧИС) или RANDBETWEEN (СЛУЧМЕЖДУ) работают, но пересчитываются при каждом изменении листа, поэтому пароли неожиданно меняются. К тому же случайные числа в Excel не предназначены для задач безопасности. Вместо этого создайте список здесь и нажмите «Копировать всё»: имена, логины и пароли будут вставлены в отдельные столбцы.

Как создать случайные пароли в PowerShell?

Прежний простой способ — Membership.GeneratePassword() — доступен только в Windows PowerShell 5.1, а в PowerShell 7 его уже нет. Проще создать список здесь, скачать файл для Active Directory и импортировать его с помощью скрипта с New-ADUser, приведённого выше.

Все ли пароли уникальны?

Да. Все пароли в одной партии разные: если новый пароль совпадёт с уже имеющимся в списке, вместо него будет создан другой. То же самое относится к PIN.

Каким должен быть хороший временный пароль?

Случайным, созданным для одного человека, используемым один раз и заменяемым при первом входе. Передайте его на распечатанном бланке или лично, а не по электронной почте, и оставьте включённой настройку «Сменить при следующем входе». Именно для этого и предназначена эта страница: для новых сотрудников, сброса паролей всей команды или нового класса.

Мой список имён куда-нибудь отправляется?

Нет. Список обрабатывается, а пароли создаются в вашем браузере. Файлы создаются на вашем устройстве, когда вы их скачиваете.
